# Сервис бронирования встреч

Сервис записи гостей на встречи с одним заранее заданным владельцем календаря.

## Термины

**Гость**:
Человек, который записывается на встречу с владельцем календаря. Регистрация гостю не нужна.
_Избегать_: клиент, зарегистрированный пользователь

**Владелец календаря**:
Единственный заранее заданный пользователь, который определяет доступное время и типы встреч и управляет бронированиями.
_Избегать_: администратор, организатор

**Страница бронирования**:
Страница для выбора типа встречи, свободного времени и записи гостя к владельцу календаря.
_Избегать_: личный кабинет гостя

**Раздел владельца**:
Раздел для работы владельца с расписанием, типами встреч и бронированиями.
_Избегать_: режим авторизации, личный кабинет
